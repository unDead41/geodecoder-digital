# GeoDecoder Digital

Keluaran web **v2.1.0** untuk GitHub Pages. Branch penerbitan: `main-digital`.

Home → Play as a Guest → nama/kategori/kelas → permainan. Guest tidak memerlukan akaun. Akaun guru/pelajar membolehkan kelas, PIN enam digit dan skor room secara langsung melalui Supabase.

Fail `index.html` mengandungi seluruh frontend. Muat turun fail ini untuk latihan sendiri secara setempat. Pembukaan laman dari URL memerlukan Internet; akaun dan room memerlukan sambungan Internet.

Repository ini mengandungi fail laman yang diterbitkan sahaja. Backend dihoskan berasingan. Rujukan keluaran dan SHA256 artifak berada dalam `release.json`. Tiada credential server disertakan.

Untuk menerbitkan: Settings → Pages → Deploy from a branch → main-digital → /(root). Push keluaran frontend yang telah diuji ke branch ini untuk kemas kini laman.
